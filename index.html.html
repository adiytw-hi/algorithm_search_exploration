What do comparisons mean?

One comparison means inspecting one array element against the target. Loop checks, arithmetic, swaps, and real elapsed time are not counted here.

Binary search has worst-case O(log n) element probes on sorted arrays. Linear search is O(n) in the worst case. Interpolation search depends on value distribution: often excellent on near-uniform numeric data, but its worst case can be O(n).
